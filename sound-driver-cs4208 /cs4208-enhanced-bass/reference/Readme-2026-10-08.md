# Odložený funkčný stav zvuku – MacBookPro11,4

Stav z **8. októbra 2026**, pred ďalším experimentovaním s údajmi z macOS.
Profil **MacBook Speakers (enhanced bass)** zodpovedá variantu B, pri ktorom
Kamil potvrdil lepší a počúvateľný zvuk. Nie je to hotová rekonštrukcia zvuku
macOS: podmaz zvýrazňujú syntetické harmonické a zvuk môže byť skreslenejší.

Tento priečinok je samostatný. Dá sa skopírovať na iný disk a po čistej
inštalácii systému použiť bez pôvodného `sound_driver` aj bez `mac_data`.
Inštalácia nevyžaduje pôvodné skúšobné skladby ani AppleHDA.kext.

## Pre aký systém

Overené na tomto konkrétnom **MacBookPro11,4**, CS4208 `10134208`,
subsystem `106b8000`, Ubuntu **26.04.1 LTS amd64**, PipeWire **1.6.2**,
WirePlumber **0.5.13**, kernel **7.0.0-38-generic**, balík **7.0.0-38.38**.

**Ovládač je viazaný na tento kernel.** Na čistom systéme s iným kernelom
ho neinštaluj násilím. Inštalátor takú inštaláciu zastaví; pre novší kernel
treba samostatne upraviť a overiť zdroj. Balík nemá DKMS ani automatické
obnovenie ovládača po aktualizácii kernelu.

Dodaná binárka Bankstown je pre amd64; na inom systéme môže potrebovať
kompatibilné knižnice alebo nové zostavenie. Pôvodný balík bol Ubuntu
`bankstown-lv2 1.1.0-3build1`; knižnica sa inštaluje iba do `~/.lv2`.

## Obsah

- `kernel/`: upravený zdroj HDA, patch, zostavenie, inštalácia a rollback.
  Priložený `.ko` je presná kópia nainštalovaného modulu zo zachovaného stavu.
- `pipewire/`: basový PCM, spojenie štyroch kanálov, balanced a enhanced bass.
- `wireplumber/`: nastavenie primárneho výstupu a softvérového mixéra.
- `vendor/`: Bankstown LV2; autorské údaje a licencie sú v `licenses/`.
- `support/`: čakanie na basový PCM pri štarte a obnovenie zvukových služieb.
- `reference/`: verzie systému, merania a staršie profily len ako referencia.
  Tieto staršie profily sa automaticky neinštalujú.
- `SHA256SUMS`: kontrolné súčty obsahu pred inštaláciou a zostavením.

## 1. Príprava čistého systému

Skopíruj celý priečinok na trvalé miesto a otvor v ňom terminál.
Môže mať ľubovoľnú cestu a meno používateľa.

```bash
uname -r
sha256sum -c SHA256SUMS
```

Kernel musí byť `7.0.0-38-generic`. Hlavičky a kompilátor pre presne túto
verziu musia byť dostupné v repozitári alebo z tvojich uložených balíkov.
Príklad inštalácie závislostí na zodpovedajúcom Ubuntu:

```bash
sudo apt install gcc-15 make kmod python3 alsa-utils mokutil \
  linux-headers-7.0.0-38-generic pipewire pipewire-bin \
  pipewire-pulse wireplumber libpipewire-0.3-modules libspa-0.2-modules
```

Nemajú byť aktívne staré experimentálne nastavenia `hda-jack-retask`, ani
odlišné `model=` / `index=` vo vlastných modprobe konfiguráciách.
Na pôvodnom systéme bol firmware jack-retask **vypnutý** a nepatrí do obnovy.
Skript neprepisuje cudzie súbory v `/etc/modprobe.d`.

## 2. Ovládač a reštart

Odporúčané je zostaviť modul na cieľovom systéme z priloženého zdroja:

```bash
bash kernel/build.sh
sudo bash kernel/install.sh
sudo reboot
```

Pre presnú pôvodnú kombináciu kernelu a ABI je priložený aj pôvodný modul;
ak ho chceš použiť, preskoč iba krok `build.sh`. Inštalátor kontroluje model,
kernel, parameter modulu aj Secure Boot. Pri zapnutom Secure Boot nepodpísaný
modul odmietne; podpis vlastným MOK tento balík nezabezpečuje.

Inštalácia pridá modul do
`/lib/modules/7.0.0-38-generic/updates/cs4208-split-test/` a súbor
`/etc/modprobe.d/cs4208-split-test.conf`. Ten zapne `split_speakers=1`
a pôvodné nastavenie `snd-hda-intel model=mbp11 index=0 enable_msi=1`.
Obnoví sa initramfs; distribuovaný modul sa neprepisuje.

Po reštarte otvor znova terminál v tomto priečinku:

```bash
cat /sys/module/snd_hda_codec_cs420x/parameters/split_speakers
aplay -l
```

Parameter má byť `Y`; má existovať **CS4208 Bass Stereo** na `hw:PCH,2`.
Ak chýba, nepokračuj používateľskou inštaláciou.

## 3. Zvukové profily – bez sudo

Odpoj káblové slúchadlá a pozastav prehrávanie.

```bash
bash install-user.sh --dry-run
bash install-user.sh
```

Prvý príkaz iba vypíše plánované súbory. Druhý zálohuje prípadné existujúce
súbory, nainštaluje konfiguráciu a Bankstown, pridá čakanie na basový PCM pri
štarte, obnoví zvukové služby a zvolí **MacBook Speakers (enhanced bass)**.
Začiatočná hardvérová hlasitosť Master bude **−20 dB**; Speaker a Bass Speaker
budú zapnuté na 100 %. Hlasitosť potom zvyšuj postupne podľa posluchu.
Tým sa úmyselne neobnovuje pôvodná hlasná poloha Master −5,5 dB.

Zálohy a inštalačný záznam sa uložia do
`${XDG_DATA_HOME:-~/.local/share}/cs4208-enhanced-bass-snapshot/`.
Pri už existujúcom zázname skript odmietne prepísať zálohu.
Nainštalované čakanie na zariadenie je v používateľskej konfigurácii,
takže po inštalácii môžeš tento balík premiestniť.

Pôvodný systém pri štarte audio služby opakovane čakal približne 50 sekúnd
na RTKit. Také čakanie samo osebe neznamená chybu profilu.

## 4. Používanie a kontrola

```bash
python3 manage-user.py check
bash select-profile.sh
```

Spusti hudbu znova. Ak si prehliadač pamätá starý výstup, v nastaveniach zvuku
mu priraď **MacBook Speakers (enhanced bass)**. Profil **balanced test**
zostáva dostupný na porovnanie bez pridaných harmonických.

Spracovanie zachováva pôvodný signál profilu balanced: primárna vetva −6 dB,
basová −3 dB, basový high-pass 60 Hz a výhybka 3 kHz. Bankstown vytvorí
pridanú zložku, od ktorej sa odčíta pôvodný signál; dva ďalšie high-pass
filtre 150 Hz obmedzia jej zvyškový základný tón. Zložka s násobkom 4 sa pridá
iba do basovej vetvy. Všetky výstupy majú pôvodné obmedzenie amplitúdy ±0,8.
Nie je to kompletná ochrana reproduktorov proti preťaženiu.

Zhoda živého profilu s úspešným B bola overená na digitálnom basovom monitore:
relatívna RMS chyba **0,0207 %**, špička **0,65171** oproti referencii **0,65173**.
To overuje prenos spracovania, nie zhodu akustického zvuku s macOS.

Známe nedoriešené veci: skreslenie a kvalita oproti macOS, kompletné dynamické
spracovanie, spoľahlivé prepínanie slúchadiel a správanie po uspávaní.
Do tohto balíka sa neprenášajú experimentálne vendorové zápisy kodeku.

## 5. Návrat späť

Používateľské profily a plugin odstráň **bez sudo**:

```bash
bash remove-user.sh
```

Obnovia sa predchádzajúce zálohované súbory. Ak boli nainštalované súbory
medzitým ručne zmenené, skript sa zastaví, aby ich bez kontroly nezmazal.
Predvolený výstup a hardvérovú hlasitosť si potom vyber ručne.
Skript nerobí `alsactl store`; hlasitosť neobnovuje ani neukladá natrvalo.

Ovládač odstráň samostatne:

```bash
sudo bash kernel/rollback.sh
sudo reboot
```

Po reštarte sa použije distribuovaný modul. Ak experiment bráni štartu,
zvoľ v GRUB iný nainštalovaný kernel a spusti tento rollback; predvolene
odstraňuje iba experiment pre `7.0.0-38-generic`.

Presná kópia nainštalovaného modulu, zhoda aktívnych profilov, samostatnosť
balíka, kontrolné súčty, syntax skriptov a skúšobná inštalácia/odstránenie
v oddelenej zložke vrátane obnovy starých súborov. Zostavenie ovládača
z priložených zdrojov na tomto kerneli prešlo; výsledný `srcversion`
`51E4CD1B66481DA40ABC644` sa zhoduje s uloženým modulom. Aktuálny systém sa pri
archivovaní nepreinštaloval ani nereštartoval. Inštalácia celého čistého
systému z tohto archívu ešte neprebehla.

`kernel/ORIGINAL_VALIDATION.md` je historický záznam z prípravy pôvodného
patchu, nie aktuálny návod; jeho staršie tvrdenia o neposkytnutej binárke
a neotestovanom prehrávaní už nepopisujú tento uložený stav.
